Interactive PRPD Simulator

Click or tap the plot to add simulated PD pulses. Each point is one pulse: where it falls in the 50/60 Hz cycle (phase) and how big it is (magnitude). Load a built-in example to see typical textbook shapes.

Synthetic, educational data only. The examples are generated by simple rules, not measured. Real PRPD patterns depend on the equipment, the sensor and measurement method, filter settings, voltage level, temperature, humidity and defect geometry. Nothing here is an equipment diagnosis.

Future extension: importing real measurement data

Version 1 is fully client-side and uses only manual points and built-in examples. The data model ({ phase, magnitude } per pulse) was chosen so a later version can import real data. Planned steps:

  1. CSV import with explicit columns: phase (°), magnitude, unit (pC, mV, dBmV…), and optional timestamp / pulse count.
  2. Ask the user for the measurement method and unit; never mix units on one plot.
  3. Show a density (2-D histogram) view, because real PRPD files contain thousands to millions of pulses.
  4. Vendor export formats (for example instrument-specific files) via documented converters only.
  5. Keep the comparison rules educational; any diagnosis remains the job of a qualified engineer.
